El sitio ya está renombrado a RutaPro Colombia. El dominio personalizado NO se configura todavía porque falta elegir y registrar el dominio exacto.

Cuando compres/confirmes el dominio:
1. En GitHub abre el repositorio > Settings > Pages.
2. En Custom domain escribe el dominio exacto y guarda.
3. Configura los registros DNS que indique GitHub y tu proveedor.
4. Activa Enforce HTTPS cuando aparezca disponible.

No publiques un archivo CNAME con un dominio supuesto: primero debe ser tuyo y estar configurado en DNS.
